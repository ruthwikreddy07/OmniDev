System Overview

OmniDev is an autonomous agentic software engineering platform that detects code failures, reasons about root causes using LLM-powered agents, generates surgical patches, validates them through sandboxed testing, and deploys fixes through a human-in-the-loop approval gate.

ReAct Agent

The core reasoning engine implements the ReAct (Reasoning + Acting) pattern. It receives a task description, iteratively uses tools to explore the codebase, identifies the root cause, and generates a patch.

Tool Chain

  • search_files — Regex search across the codebase
  • read_file_lines — Read specific line ranges from files
  • apply_patch — Apply a targeted code patch
  • get_file_tree — List the project file structure
  • run_tests — Execute tests in sandboxed subprocess

MCP Server

Standard JSON-RPC 2.0 Model Context Protocol implementation that exposes codebase tools over HTTP. Any MCP-compatible agent framework can connect.

POST /api/mcp
{
  "jsonrpc": "2.0",
  "method": "tools/call",
  "params": { "name": "search_files", "arguments": { "pattern": "def list_jobs" } },
  "id": 1
}

Job Manager

Background job runner with SQLite persistence. Manages job lifecycle (queued → running → pending_approval → done/failed), WebSocket broadcasting, and human-in-the-loop approval.

Test Runner

Sandboxed subprocess test executor with configurable timeout. Runs the project test suite and captures stdout/stderr for the agent to analyze failures.

WebSocket

Connect to /ws/{job_id} for real-time streaming of agent actions, log entries, and approval requests for a specific job.

Webhooks

GitHub webhook endpoint filters for opened and labeled actions. Issues with the ai-fix label are automatically queued as agent jobs.
