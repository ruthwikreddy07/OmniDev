Agent Playbook

Rules, constraints, and governance policies for the autonomous agent

01
Sandbox-First Execution
All test executions run inside isolated subprocess sandboxes with strict timeouts. No direct filesystem mutation outside the project scope.
securityisolation
02
Human-in-the-Loop Gate
Critical patches require explicit human approval via WebSocket before deployment. No autonomous merge without operator consent.
approvalsafety
03
Surgical Patching Only
Agent applies minimal, targeted code changes. Wholesale file rewrites are forbidden. Patches must be diff-formatted and reversible.
precisionreversible
04
Failure Escalation Protocol
If the agent fails after 3 retry cycles, the job is marked as failed and escalated to the operator with full reasoning trace.
retryescalation
05
Credential Isolation
API keys and tokens are injected via environment variables only. The agent never has persistent access to raw credential storage.
secretsenv-vars
06
Rate-Limited LLM Calls
Exponential backoff retry with configurable max attempts prevents runaway API costs. Free-tier budget enforcement is built-in.
cost-controlrate-limit
Governance Controls
Automatic Test Validation
Every patch must pass the full test suite before reaching the approval gate
Audit Logging
All agent actions, tool calls, and decisions are logged to SQLite for full traceability
WebSocket Real-Time Monitoring
Live streaming of all agent activity to the operator console
Scope Boundary Enforcement
Agent cannot access files outside the designated project directory
